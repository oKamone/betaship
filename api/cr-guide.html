Betaship · CR Integration Guide

1つのAPIで、
AIツールが完成する。

Auth・課金・クレジット管理はBetashipが持つ。CRはツールのロジックだけ書けばいい。

Overview

CRがやること：POST /api/ai を1回叩く。
それだけで、Betashipが以下を全部処理する。

  • ✓ JWTでユーザー識別
  • ✓ クレジット残高チェック
  • ✓ Claude API呼び出し
  • ✓ 使用量に応じたcr消費
  • ✓ 呼び出しログ記録

Getting Started

1

Betashipに登録する

オーナーに連絡して2つを設定してもらう。

  • product_id の発行（例: my-tool）
  • CRのドメインをCORSホワイトリストに追加
開発中は free_mode: true にしてもらうとクレジットを消費せずにテストできる。 本番移行時に billing_active: true に切り替える。
2

Betaship Authを組み込む

Betashipの Supabase クライアントでログインする。これがSSO（艦隊共通パスポート）になる。

// npm install @supabase/supabase-js
import { createClient } from '@supabase/supabase-js'

// オーナーからもらうキー（公開鍵なので安全）
const supabase = createClient(
  BETASHIP_SUPABASE_URL,
  BETASHIP_SUPABASE_ANON_KEY
)

// Googleログインボタン
await supabase.auth.signInWithOAuth({ provider: 'google' })

// セッション取得
const { data: { session } } = await supabase.auth.getSession()
3

APIを呼ぶ

Claude API の代わりに Betaship の proxy を叩く。service に自分の product_id を渡す。

const res = await fetch(
  'https://betaship-api-767603267032.asia-northeast1.run.app/api/ai',
  {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      // Betashipのセッショントークンをそのまま渡す
      'Authorization': `Bearer ${session?.access_token}`
    },
    body: JSON.stringify({
      service:    'my-tool',      // 登録した product_id
      messages:   [{ role: 'user', content: userInput }],
      model:      'claude-haiku-4-5-20251001',
      system:     'あなたは...',  // systemプロンプト（任意）
      max_tokens: 1024
    })
  }
)

const { content, cr_used } = await res.json()
model の選択肢：
claude-haiku-4-5-20251001 — 軽量・高速（推奨）
claude-sonnet-4-5-20251022 — 高品質（4倍cr消費）

Response

{
  "content":     "AIの返答テキスト",
  "cr_used":     3,          // 今回消費したcr数
  "tokens_in":   120,
  "tokens_out":  180,
  "stop_reason": "end_turn"
}

Error Codes

Status error 対応
401 unauthorized JWT未送信 or 期限切れ。supabase.auth.getSession() で再取得してリトライ。
402 insufficient_credits クレジット残高不足。購入ページ（betaship.web.app/#pricing）に誘導する。
429 daily_limit_exceeded 未ログイン枠の上限。ログインを促す。
500 （Claude APIエラー） リトライ or エラー表示。

残高取得（任意）

ユーザーのクレジット残高をUIに表示したい場合。

const res = await fetch(
  'https://betaship-api-767603267032.asia-northeast1.run.app/api/credits',
  { headers: { 'Authorization': `Bearer ${session?.access_token}` } }
)
const { total_cr, plan, plan_limit } = await res.json()

Launch Checklist

  • product_id を発行してもらった
  • ドメインがCORSホワイトリストに追加された
  • free_mode: true でローカルテスト完了
  • insufficient_credits エラー時に購入ページへ誘導している
  • billing_active: true に切り替えてもらった
